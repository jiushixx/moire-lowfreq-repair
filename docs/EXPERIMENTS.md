# 从探索到最终项目

## 核心问题
冻结去摩尔纹网络在新数据上可能出现显著低频色偏。我们研究先做简单颜色校正、再训练空间残差头是否能以少量训练提供额外收益。UHDM用于保留源域工作和比较域差异，DCID用于少样本修复。

| 阶段 | 观察/决定 | 对应文件 |
|---|---|---|
| 分块、尺度、预算探索 | 硬拼块接缝、上下文与颜色偏移混杂；GT oracle只说明潜力，启发式没有可靠收益；停止预算路由主线 | experiments/exploration |
| 同视野多尺度融合 | UHDM开发集band 22.1661 vs原生21.9091；保留频段融合 | experiments/source_fusion |
| DCID直接迁移 | 颜色偏差明显；输入均值校正成为强基线 | baseline.py、calibration.py |
| 解码器微调/源域回放 | 没有超过DCID均值基线；源域也退化，均值先验是混杂因素 | controls/joint_decoder.ipynb |
| 全局ridge校准 | 不能同时超过两域各自强基线 | controls/global_calibration.ipynb |
| 共享空间头与门控 | 两者均未超过各自域强基线，空间也未优于门控 | controls/shared_spatial_gate.ipynb |
| 来源独立空间修复 | DCID验证100步最佳；500步退化；UHDM独立头不保留 | repair.py |
| 固定方法新test子集 | UHDM原融合有效；DCID100步空间头在均值校正之上有效 | evaluation.py、results/frozen |

## 训练规模与计算
UHDM原融合：100训练、10开发验证，2种融合头各2000步；主干不训练。
后续缓存：DCID12训练/8验证，UHDM20训练/10验证，固定50张中心768预测。
共享头与门控各1000步；独立头每域500步、每100步评价。最终DCID权重来自第100步开发选择；UHDM独立修复头第0步最好，因此不采用。
这些都是不同设置的实验，不把多轮验证增益累加，也不把早期10张与后期20张分数直接相减。

## 可以写进报告的工作量
配对数据按需下载和审计；分块/视野混杂诊断；多尺度分频融合；DCID颜色失配诊断；多种轻量适配对照；从强基线出发的空间残差学习；固定独立文件子集验证及逐图分析。
创新定位为课程项目中的问题诊断、方法组合和小样本实证，不声称发明频率分解或首次提出空间校正。

最终成绩来自 frozen_20261108_035252_results.zip。原始模型、采样种子、协议保存在results/frozen；先前开发CSV放在results/development。GT只用于监督训练、开发选择与离线指标；最终推理不输入GT。
